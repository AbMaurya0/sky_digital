# Image Assets

This folder contains all image assets used in the Sky Digital application.

## Structure

- `logo.png` - Sky Digital logo (main brand logo)
- `web.jpg` - Web development course image
- `mobile.jpg` - Mobile app development course image  
- `design.jpg` - UI/UX design course image
- `data.jpg` - Data science course image

## Usage

- Logo is used throughout the app via the `LogoWidget` component
- Course images are referenced in the `SampleData` class in `lib/data/sample_data.dart`

## Guidelines

- Use optimized images (compressed for web)
- Maintain consistent aspect ratios
- Use descriptive filenames
- Keep file sizes reasonable for web performance
- Logo should have a transparent background for best results
